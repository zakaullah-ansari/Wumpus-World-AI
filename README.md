# Wumpus-World-AI

An interactive 4x4 cave grid simulation based on the classic AI benchmark
environment — combining local knowledge-based agent reasoning with a
Firebase backend and LLM-based tactical advice. Built as a 2-hour,
hands-on Flutter + Dart + Firebase + AI Agent Reasoning workshop for
3rd-year engineering students.

## Start here

📘 **[`WORKSHOP_GUIDE.md`](./WORKSHOP_GUIDE.md)** — the full curriculum:
elevator pitch, syllabus-to-feature mapping, concept analogies, the
120-minute trainer agenda, complete annotated code, and resume bullet
points for students.

## Code

- **[`wumpus_world_ai/`](./wumpus_world_ai)** — complete, working reference
  solution (trainer-only).
- **[`wumpus_world_ai/starter_kit/`](./wumpus_world_ai/starter_kit)** — the
  "fill-in-the-blanks" repo handed to students, with 5 guided `TODO (BLOCK
  n)` exercises and everything else pre-built.

```bash
cd wumpus_world_ai        # or starter_kit for the student version
flutter pub get
flutter run -d chrome
```
